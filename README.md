# Actividad Parcial 2 — Fundamentos de Inteligencia Artificial

Repositorio de trabajo para las seis secciones de la Actividad Parcial 2 de Fundamentos de Inteligencia Artificial.

## Contenido
- `reportes/`: seis informes PDF individuales con planteamiento, método, resultados esperados/obtenidos, análisis y referencias.
- `src/`: programas Python comentados para ejecutar las actividades.
- `datos/`: datos de ejemplo del proyecto.
- `requirements.txt`: dependencias.
- `DECLARACION_IA.md`: declaración transparente de uso de IA.
- `README.md`: instrucciones y estructura.

## Requisitos
Python 3.10 o superior.

```bash
python -m pip install -r requirements.txt
```

## Ejecución
Desde la raíz del repositorio:

```bash
python src/s1_aplicaciones_ia.py
python src/s2_modelado_busqueda.py
python src/s3_busqueda_local.py
python src/s4_bfs_dfs_laberinto.py
python src/s5_a_estrella_dijkstra.py
python src/s6_algoritmo_genetico_tsp.py
```

Los programas imprimen resultados en consola. Los que generan visualizaciones guardan sus imágenes en `resultados/` (la carpeta se crea automáticamente). Si no se dispone de interfaz gráfica, los cálculos de consola siguen funcionando.

## Antes de entregar
1. Sustituye los campos `[NOMBRE COMPLETO]`, `[MATRÍCULA]` y `[DOCENTE]` de los reportes si tu profesor los solicita.
2. Revisa los resultados al ejecutar cada script y actualiza las capturas/valores de los PDF si cambian.
3. Sube la carpeta a un repositorio público de GitHub, como indica la consigna.
4. Verifica que el enlace público abra sin iniciar sesión.
5. Entrega cada PDF de manera individual en la plataforma escolar y pega el enlace del repositorio.
